# LEADR - Lightweight Game Leaderboard API

**Cross-platform leaderboards for game developers**. Add feature-rich leaderboards to your game on any platform, any engine, and unify all your players in one place. Open-source, with built-in anti-cheat and more, without trying to be your entire backend.

> [!WARNING]
> This repository is no longer maintained and has been replaced by [LEADR Open Source](https://github.com/LEADR-official/leadr-oss).
>
> [LEADR](https://www.leadr.gg) is also available as a hosted version with a free tier - [get started here](https://docs.leadr.gg/latest/quick-start/)
